# sxxp_constituents
List of STOXX Europe 600 historical constituents from 2026/11/05 to present. CSV format where each date contains a list of the constituents.

## Description of Files

**'sxxp_constituents.csv'** current STOXX Europe 600 composition from Wikipedia and output from **'sxxp.py'**

**'sxxp_historical_components.csv'**  contains historical STOXX Europe 600 index membership from 2026 til present. Output from **'sxxp.py'**
